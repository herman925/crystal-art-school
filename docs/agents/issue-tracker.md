# Issue tracker

Issues for this repo live in **GitHub Issues** on `herman925/crystal-art-school`,
managed with the `gh` CLI.

- Create: `gh issue create --title "…" --body-file <file> --label ready-for-agent`
- List: `gh issue list`
- Close: `gh issue close <number>`

## PRs as a request surface

**Off.** Pull requests are not treated as incoming requests for triage.

## Repository visibility — read before writing an issue

This repository is **PUBLIC**. It serves the demo at
`https://herman925.github.io/crystal-art-school/`, which requires public visibility on a
free GitHub account.

Everything written into an issue is publicly readable and search-indexed, including by the
client. Editing or closing an issue does not unpublish it.

Therefore:

- Write issues as neutral status, not as commentary on the client or on prior work.
- Never paste meeting transcripts, client correspondence, photographs of client feedback,
  pricing, or commercial terms into an issue.
- Those materials are gitignored on purpose — see the "Client working material" block in
  `.gitignore`. Reference them by section number, never by quoting them at length.
