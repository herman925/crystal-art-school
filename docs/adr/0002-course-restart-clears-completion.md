# Course restart clears completion while retaining access

The owner chose the prototype's reset behaviour over replay with progress retained on
2026-11-01. Restart applies only to the current student and selected enrolled course:
it clears completion and returns to lesson 1, preserving enrolment, purchases and other
courses. This is a deliberate loss of saved completion, not a cancellation or a refund.

Decision record: [Lesson parity: settle and restore the restart-control and teaching-card contract](https://github.com/herman925/crystal-art-school/issues/220).
