# Courses

**Course content and course prices use separate workflows.** Use the course editor for titles, images, descriptions and lessons. Set or change paid-course prices only through the confirmed Course prices workflow (available after handover), not the ordinary course-save button. Use [Course Prices](/course-prices) after account handover.

Start from **Content hub → Manage Courses**. In the course list, click the course title
to open Tutor's builder. Use **Add course** on the hub for a new draft. Only courses
assigned to your account can be edited.

| Field | Where it shows |
|---|---|
| **Title** | Course card and course page |
| **Course Card Cover** | The catalogue card cover. It is also the course page fallback if Gallery Photo 1 is empty |
| **Gallery Photos 1–5** | The five course-page photographs. Photo 1 appears first; clicking a thumbnail changes the large photograph |
| **Course Subtitle** | The optional line under the course highlights video |
| **Course Media Label** | The medium shown with the course title, such as Sketching & Watercolour |
| **Regular price / Sale price** | Both; change only through the confirmed Course prices workflow (available after handover). A sale price crosses out the regular one |
| **Difficulty level** | The small chips under the title |
| **Category** | The tag above the title |
| **Description** | The paragraph under the course title |
| **What will I learn** | The "By the end of this course" list |
| **Targeted audience** | The "This course suits" cards |
| **Materials included** | The "What comes with it" list |
| **Topics and lessons** | The syllabus |

If a course has no materials listed and no files, the 'What comes with it' section is left out of the page.

## Two fields with a shape to follow

**Targeted audience** is split at a dash. Type Complete beginners — you have never held a
brush and the site shows the first half as a heading and the second as its explanation. No
dash means no explanation, which still works but reads flat.

**What will I learn** and **Materials included** are one item per line. Do not number them;
the site does that.

## Prices

Use **Course prices** and its separate review/confirmation step for paid-course amounts; follow [Course Prices](/course-prices) after handover. Enter numbers without a currency symbol, and leave Sale empty when no sale is intended.

The agreed course currency is GBP (£). **Currency and cart settings are managed by the site administrator**, not through your content-editing controls. Do not change them in Tutor Settings; ask the site administrator if anything appears wrong.

The lesson count and total runtime under each course are worked out from the lessons
themselves. Use the lesson count-per-film field when one film covers more than one numbered
lesson; use the actual film duration for the runtime. Do not type totals into course descriptions.

## Order of the courses

Courses use their saved Order, lowest first; date breaks ties. If you need a different
order and cannot find an Order control, request the change from the site administrator.

The same order decides the row of courses on the homepage, which shows the first ten
published courses.

Open the course in Tutor's builder. The **Basics** tab has **Gallery Photo 1
(Initially Shown)** and **Gallery Photos 2–5** below the description. For each slot,
choose or upload the original photograph, then save the course and reload it to check the
selection. WordPress generates the smaller image sizes.

These five photographs are separate from **Course Card Cover**. If Photo 1 is empty,
the course page can use the cover and lesson photographs as fallbacks. Fill all five slots
when you want the complete intended gallery.

The thumbnails change the large photograph when clicked; the gallery does not advance
automatically. Clearing a slot removes its selection without deleting the image from Media.
Paid lesson references and downloads are separate from these public photographs.

On the homepage card, one of the four small images is picked at random each time the page is
loaded, so the card keeps changing slightly without you doing anything.

If a course is missing its photographs, fill the intended slots and check the cards before publishing or advertising it. Ask the site administrator if the pictures or editing controls you expect are unavailable.

## The filters look after themselves

The Courses page has a column of filter and sort controls down the left. There is nothing to
set up: every button is built from the courses that are actually published.

A group of filters appears only when there are useful choices to offer. For example, if every published course has the same medium, a medium filter may be omitted. Choose from the available categories; request a new category from the site administrator rather than using category-management settings.

The same goes for difficulty, length, price and the sale filter. Fill in a course properly
and it becomes findable; leave a field empty and the filter for it stays away.

## Who can watch a course

There are no membership levels. Someone who has paid for a course can watch that course's
video lessons and download its materials. Someone who has not can still read every public
page — the homepage, About, the gallery, the blog and the free videos.



## Draft and published

A draft is not a published course. For a new paid course, save the content as a draft, set and confirm its first price through **Course prices**, reload the same saved course, and publish only when the content, price and launch timing are agreed. A saved price does not publish the course.

For an already published course, use the same confirmed price process for money changes; do not use the ordinary content-save button to change its price. Follow [Course Prices](/course-prices) after account handover, and ask the site administrator if the current course status is unclear.

Use **Additional → Attachments → Upload Attachment** in the course builder. Upload the
file in the Media window, choose **Select**, then save the course with **Update**. Reopen
the course to check its saved file list. Public course-gallery photographs and paid
attachments have separate purposes; upload separate copies when the same picture is
needed in both places. An image already used by public content cannot be made a paid
attachment.

For a replacement, remove the old item from the attachment list, add the replacement,
and save. Simply uploading another file adds it; it does not remove the previous one.
Give versions distinct names so you can identify the intended replacement.

Removing an attachment and saving revokes that course student's old download link.
A shared file stays available only if another current course attachment gives that
student access. Removing a selection is different from deleting the file permanently
from Media. Do not permanently delete a file still used by another course or page.

Reopen the saved course and check the intended file list before directing students to it.

## New or replacement lesson films

Ask the site administrator to arrange a new film or replacement. Editing the course does
not upload the film. You can still edit the lesson title, description and position.

Keep paid films out of the public Media library. Never paste a hosting password into a lesson.
