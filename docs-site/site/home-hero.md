# The homepage banner

> **Draft — the combined editing page awaits installation, checks and account handover.**

Open **Content hub → Home → Edit Home**. The homepage banner, page text and photographs
are on the same editing page. The banner controls are grouped by slide.

The banner is a carousel of **three slides**. Each slide has four fields you control:

- **Main title**
- **Description**
- **Large image**
- **Small image**

There are always exactly three slides. Adding a fourth or dropping to two is not something
the settings can do.

## About the two images

Each slide shows a large image and a smaller one overlapping it. The site crops whatever
you upload to fit its slot, so the layout does not break when you change a picture — but a
photo cropped to a shape it was not composed for can lose its subject.

The recommended size for each slot is written next to the field. Uploading
something close to that shape gives the best result.

## Save and view

Choose or replace each intended image, then press **Save Home**. Choosing an image alone
does not save it. This button also saves the other fields on the Home editing page.

Use **View saved page** to open the website in another tab. This shows saved changes, not
an unsaved preview. Check the banner at a narrow window width as well as a wide one.
The two images move relative to each other on smaller screens.

Clearing a banner field leaves it blank. **Clear slot** removes that slide image when saved;
it does not delete the photograph from the media library. Keep the first slide's title filled
in, because it is the page's main heading.
