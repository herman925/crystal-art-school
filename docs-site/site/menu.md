# Request a menu change

The menu across the top is maintained by the site administrator. To request a change, send:

1. The current label and the wording you want.
2. The page it should open.
3. Its intended position, if the order should change.

The site administrator will check the menu on a phone as well as a wider screen. Editing page text does not
change the menu. Do not rename or delete account/checkout pages to repair a link.
