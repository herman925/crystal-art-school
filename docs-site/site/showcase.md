# Student work

**Student work** in the dashboard menu. One entry per piece. They appear pinned to the cork
board on the Student showcase page.

| Field | Notes |
|---|---|
| **Title** | The name of the piece. Can be left empty |
| **Featured image** | The photograph. Required |
| **Student name** | In the **Credit** box on the right. Can be left empty |
| **Medium** | In the **Credit** box on the right, e.g. Watercolour |
| **Page attributes → Order** | Position on the wall, lowest first |

## The photograph is the piece

A piece with no photograph does not appear on the wall at all. There is nothing else to
show, so there is nothing to pin up.

The **Student work** list has a **Picture** column that reads "Missing — not shown on the
wall" when this happens, so you can spot it without opening every entry.

Each photograph is cropped to a square. Shoot the painting square-on and crop close to its
edges before uploading.

## Use the student's username

Use the student's agreed public username, not their legal name. Obtain permission before publishing a credit or photograph; having an account is not permission to publish their details.

If you are not sure what a student is happy to have published, leave the box empty. The
piece still goes on the wall, just without a credit.

## Medium builds the filter buttons

The row of buttons above the wall is built from whatever media you have actually used.
Nothing to configure — type "Watercolour" on a few pieces and a Watercolour button appears.

Two small things worth knowing:

**Capital letters do not matter.** "Watercolour" and "watercolour" become one button.

**Spelling does.** "Water colour" with a space makes a second, separate button beside the
first. The box suggests the words you have already used — pick from those rather than
retyping.

The row of buttons only appears once you have used **two different media**. With one, there
is nothing to filter, so it stays hidden.

## Order on the wall

**Page attributes → Order**, lowest first. Pieces with no number fall in after the rest,
newest first.

There is no drag-and-drop here. The number in that box is what decides it.

## While the wall is empty

The page says "No student work is published yet." That is what visitors see now. Everything
else on the page — the heading and the closing invitation — is already there and waiting.
