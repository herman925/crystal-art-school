# Saving and publishing

## Pages with one Save button

**Edit Home**, **Edit About** and **Site-Wide Edit** each save the fields on that page
together. For example, **Save Home** also saves slides hidden behind the other slide tabs.

After saving, use **View saved page** where offered. It opens the saved website in another
tab; it does not show work you have not saved.

## Entries with a publication status

Articles, artwork, free films, student work and questions have their own entries.

- **Save draft** keeps unfinished work off the public website.
- **Preview** shows the pending entry where that control is available.
- **Publish** makes a new entry public.
- **Update** saves changes to an entry that is already public.
- Moving an entry to **Trash** removes it from the public lists. Use this only for the entry you intend to withdraw.

For a repeating list such as FAQ, check the actual FAQ page after saving the entry.

## Courses and lessons

A course saves its description, gallery and other course fields. A lesson has its own
**Update** button. Save each lesson you change, then save any separate course changes.
For a new paid course, save a draft and [set its first price](/course-prices) before publishing.

## Pictures and files

Selecting an image, setting a crop or uploading a file stages that choice. Save the page,
course or lesson afterwards. Reload it to check that the selection stayed.

Clearing a picture slot removes its selection; it does not delete the original from Media.
Avoid **Delete permanently** when the same upload is used elsewhere.

## A save did not give a clear result

Do not press Save repeatedly. Open the saved page or a fresh list to check what happened.
Keep any unsaved words before reloading. If the result is still unclear, [ask Herman](/help).
