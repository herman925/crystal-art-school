# Prices, orders and student access

These tools are available in your Content Hub. They are separate because they change different things.

| Your task | Use | Important difference |
|---|---|---|
| Set a paid-course price or switch a sale on/off | [Course builder prices](/courses#prices) · [Alternative price screen](/course-prices) | Save as Draft keeps the course unpublished; old orders are unchanged |
| Offer a discount code | [Coupons](/coupons) | Applies to future eligible checkout; it is not a refund |
| Find an order or review its status | [Sales](/sales) | An order status is not proof that money arrived |
| Correct one student's access | [Course Access](/course-access) | Does not take or refund a payment |

## The routine for a change

1. Identify the exact course, student or order.
2. Check the current state and the agreed change.
3. Read the review screen before confirming.
4. Confirm once, then check the fresh saved result.

If the result is unclear, stop and [ask the site administrator](/money-help). A second change can make
an uncertain result harder to resolve.

Payment-provider settings, tax setup, refunds and bank disputes stay with the site administrator. These
instructions do not open payments or registration, and example amounts are not approved prices.
