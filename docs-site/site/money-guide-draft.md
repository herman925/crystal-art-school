# Money and access: start here

> **Draft — not approved for live use.** The final screens and behaviour must be checked by Review before these instructions are handed over. This draft is not permission to make live changes.

## Quick safety checklist

1. Check the exact course, student or order. A similar name is not enough.
2. Write down the current state and the intended change. Use agreed amounts, not guide examples.
3. Use one change tab at a time. Do not ask someone else to change the same item while your confirmation is open.
4. Read the review page before confirming. Opening a form is not saving it.
5. Confirm once and wait. If the response disappears, check a fresh list before doing anything else; a missing response does not prove nothing happened.
6. Check the saved result. If it is unexpected or uncertain, stop and ask Herman. Do not make a second money change to repair the first.

Never share a confirmation link, password, card details or another person's account. A support screenshot should show only the information needed to identify the problem.

## Choose the right screen

| What you need | Read | What it does not do |
|---|---|---|
| Set a new draft's first paid price or change a paid course's price | [Course prices](./course-prices-draft.md) | Does not publish the course, rewrite existing orders or issue refunds |
| Offer a code for future checkout | [Coupons](./coupons-draft.md) | Does not refund an earlier purchase |
| Review an order, change an allowed pending status, export the list | [Sales](./sales-draft.md) | Does not collect a payment or issue a refund |
| Give or remove one student's course access | [Course access](./course-access-draft.md) | Does not change an order or payment |
| Resolve an uncertain save, warning or wrong result | [Troubleshooting](./money-help-draft.md) | Does not authorise repeated or corrective money actions |

A course price, order status, payment status and student's access are separate things. Do not change one simply to make another look right.
