# Correct a student's course access

**Open Content Hub → Course Access.** Use this only for an agreed one-off correction.
It does not charge money, create/change an order or issue a refund.

1. Enter the existing student's login or email.
2. Choose the exact published course and **Add access** or **Remove access**.
3. Choose **Review change**.
4. Check the student, course and current access, then read the warning.
5. Use **Confirm give access** or **Confirm remove access** once.
6. Check the saved result.

Adding access gives the course without recording a payment. Removing access removes the
selected course's active enrolments; it keeps the student account and cancelled enrolment record.
Do not use it just to make an order or payment label look right.

Staff accounts are not valid targets. If access has changed since review, start with a
fresh review. If the result is unclear, [ask the site administrator](/money-help) before another attempt.

## Refund or bank-dispute request

Send the site administrator the order number and the student's report. The site administrator handles the payment and checks
access separately. Do not remove access automatically, refund in a payment dashboard or
borrow an administrator login. Another valid purchase/grant may still give access.
