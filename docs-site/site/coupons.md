# Create a discount code

**Open Content Hub → Coupons → Add coupon.**

1. Enter a recognisable title and a distinct code: 3–40 letters, numbers, dashes or underscores.
2. Choose **Percentage** or **Fixed amount**, then enter the discount.
3. Set the start date and optional expiry.
4. Set **Total uses** and **Uses per student**. Blank means no limit; a limit must be at least one.
5. Read the form again, then choose **Save coupon** once.
6. Open the fresh coupon list and check the code before sharing it.

## Check the size of the offer

Percentage **20** means 20%; fixed amount **20** means £20. A percentage cannot exceed 100.
The current tools create codes for **all courses**; do not describe a code as restricted
to one course or one person.

**A 100% percentage code makes the course free.** Tick its separate confirmation only
when that is intended. A large fixed discount can also remove the amount due on a cheaper course.

Dates use YYYY-MM-DD. Ask the site administrator to check an exact time-zone/cut-off promise before advertising it.

## End or change an offer

Use the coupon's edit or deactivate control. A used code cannot be renamed or deleted;
deactivate it if it must stop being offered. This does not refund past orders or remove
access already granted.

If the save result is unclear, check the list before doing anything else. Do not submit
again or create a replacement code until the site administrator has checked the first result.
