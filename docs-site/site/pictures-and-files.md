# Pictures and files

Start from the page, course, lesson or entry that needs the picture or file. Its own chooser
puts the selection in the right place; uploading to Media by itself does not place it on a page.

## Choose or replace a public picture

1. Open the intended image slot or **Featured image** control.
2. Use **Media Library** for a suitable existing public image, or **Upload files** for a new one.
3. Check the selected thumbnail and the image's description or **Alt Text**, where offered.
4. Use that chooser's selection button, then save the page or entry itself.
5. Reopen the editor and inspect the saved website page.

Use a clear description for an informative image. Do not put passwords, private notes or a
student's unapproved personal details in a filename, title or image description.

## Crop and framing

Home's **Reposition** control changes how that slot frames a picture. **Use This Crop** stages
the choice; **Save Home** applies it. The original upload is retained. The same image can be
cropped differently in a banner, card or phone layout, so inspect the places where it appears.

Prepare the image in approximately the shape suggested beside the field. A wide picture is
usually a better banner source than a portrait. Check text and important detail near the edges.

## Public pictures and paid course files are different

| You are adding | Use |
|---|---|
| A public page, artwork, article or certificate picture | That page's picture slot or Featured image |
| A public course-gallery photograph | **Course → Gallery Photos 1–5** |
| Course-wide notes or reference photographs | **Outcomes/Materials → Attachments** |
| One lesson's exercise files | That lesson's **Exercise Files** |
| A lesson video file | That lesson's **Lesson video → Upload video** |
| A public course highlight film | **Course → Course Highlights Video** |
| A free YouTube film | The Free Videos entry's **Video link** |

A public photograph cannot become private just by selecting it as paid material. Upload a
separate copy for paid course use. A draft or private entry also does not make a public image
address private. For a certificate, upload only the scan version that may be made public.

## Replacing and removing

Selecting a replacement does not save it until you save its page, course or lesson. Removing
a selection removes that use of the file; it does not normally delete the upload itself.

For course/lesson files, remove the old selection, add the new version and save. Give versions
distinct names, then check the student's actual materials list. An old protected download
stops when that student's final qualifying course/lesson reference is removed. Other valid
uses can keep the same file available to that student.

Do not use **Delete permanently** on an upload still used elsewhere. If an image must disappear
from public access entirely, ask the site administrator to check its other uses and stored copies.

## If a picture or file seems missing

- Check the saved entry, publication state and intended image slot first.
- If the chooser says an image is already public or cannot be used as paid material, upload a separate copy.
- Keep your original video file until upload, processing, preview and the lesson save are verified.
- If the save result or file access is unclear, keep the exact message and [ask for help](/help).
