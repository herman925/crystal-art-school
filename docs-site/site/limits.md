# What stays with the site administrator

Your editing tools let you maintain content while keeping the site's structure consistent.
You do not need access to every WordPress menu to do that work.

## Send a request for these changes

- Menu labels, destinations and order.
- Page structure, fixed headings, buttons, colours, fonts and icons.
- Currency, checkout, payment-provider or tax configuration.
- Refunds and bank disputes.
- Other users' accounts, plugins, technical repairs and backups.

Tell the site administrator what visitors should see and on which page. They can check the change across
phone and desktop layouts.

## The tools that are yours

You can maintain assigned content and use the agreed [course-price, coupon, Sales and
Course Access tools](/money-guide). Those tools do not open site administration.
You can also manage [your certificates, their order and the pinned highlight](/certificates).

## Tutor, Bunny and software updates

Tutor's course and lesson editors open inside WordPress using your usual website login.
The upload control sends lesson films and public course highlights to Bunny behind the scenes;
you do not need a separate Bunny login or any video embed code. Free Videos keeps its
YouTube-link workflow.

WordPress, Tutor LMS, Elementor Pro and other plugin updates stay with the site administrator,
along with licences, backups and compatibility checks. If an update notice appears, send it
to the site administrator. It does not mean you need to complete an update before editing content.

Student photographs and credits still need the student's permission. Keep the work as a draft if permission to publish the picture is unclear. When the picture may be published but the name should be omitted, keep the correct **Registered Student** linked and select **Hide public name credit**. The student's Showcase preference still applies. See [Student work](/showcase).
