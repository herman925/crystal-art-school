# What stays with the site administrator

Your editing tools let you maintain content while keeping the site's structure consistent.
You do not need access to every WordPress menu to do that work.

## Send a request for these changes

- Menu labels, destinations and order.
- Page structure, fixed headings, buttons, colours, fonts and icons.
- Currency, checkout, payment-provider or tax configuration.
- Refunds and bank disputes.
- Other users' accounts, plugins, technical repairs and backups.
- Awards/certificate scans and wording that needs checking before publication.

Tell the site administrator what visitors should see and on which page. They can check the change across
phone and desktop layouts.

## The tools that are yours

You can maintain assigned content and use the agreed [course-price, coupon, Sales and
Course Access tools](/money-guide) after handover. Those tools do not open site administration.

Student photographs and credits still need the student's permission. Use **No Student Credit**
if permission or the intended public name is unclear.
