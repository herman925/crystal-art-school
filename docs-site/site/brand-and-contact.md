# Logo, signature and contact details

Start from **Content Hub → Site-Wide Edit**. Contact details, social links,
the logo and both signature images are on one editing page. Change the intended fields and
press **Save Site-Wide Edit**. This saves all fields on the page together.

## Logo and signature

Three separate images, used in three places:

| Setting | Where it appears |
|---|---|
| **Header logo** | Top left of every page |
| **Hero signature mark** | Inside the banner at the top of most pages |
| **Footer signature** | Bottom of every page |

They are separate on purpose — the header logo is small and wide, the signature is a
different shape. Swapping one does not swap the others.

The hero signature mark appears on the banner of **every page that has one**, so changing
it changes several pages at once. That is worth knowing before you try a new version.

Use **Choose image** or **Replace image** for the intended slot. **Use shipped default**
restores the original picture when you save; it does not delete an uploaded picture.

Four settings: **Instagram URL**, **Facebook URL**, **YouTube URL**, **Contact email**.

Paste the full web address for the social links, starting with https://. The site works
out what to display from the address, so you do not type your handle separately.

These four values feed the footer of every page, the FAQ page, the About page and the
homepage strip. One change updates all of them.

Clearing a value can leave its icon or button visible with an empty destination. It does not
reliably hide the link. Ask the site administrator if you want a contact channel removed.
