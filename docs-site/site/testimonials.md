# Student comments on the homepage

**Testimonials** in the dashboard menu. Three appear on the homepage.

Each entry has two parts:

- **The body** — what the student said. Type it in as plain text.
- **"Who said it"** — a dropdown on the right listing every member. Pick the student.

You do not type the student's name or upload their picture. Both are read from that
student's own account, so if they change their display name or photo it updates here
automatically, and it can never disagree with what they see elsewhere on the site.

**Page attributes → Order** controls which three show, lowest numbers first.

If nothing is published, the section disappears from the homepage rather than showing an
empty space.

## One thing to check first

These cards publish a real student's name and profile picture on your public homepage. Make
sure the student has agreed. The webmaster is separately sorting out the wording in the member
terms that covers this.
