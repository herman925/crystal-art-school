# Change a course price

**Open Content Hub → Course Prices.** Change paid-course prices here, separately from the
ordinary course-content save.

## Existing paid course

1. Find the course and read its current **Regular** and **Sale** amounts.
2. Enter the agreed new amounts, then choose **Review change**.
3. Check the course title and the **Now / New** table.
4. Fill the four confirmation boxes from that table:

| Confirmation box | Copy this value |
|---|---|
| Current regular | Regular under Now |
| Current sale | Sale under Now, or leave empty if none |
| New regular | Regular under New |
| New sale | Sale under New, or leave empty if none |

5. Choose **Save the new prices** once. Look for **The price is saved**, then check the fresh list.
6. Reload an already-open course builder before its next content save.

For example, changing £60/£45 to £68/£52 means Current regular **60**, Current sale **45**,
New regular **68**, New sale **52**. These are example amounts only.

## New paid course

1. Use **Add course** on Content Hub. Enter its content and save a draft.
2. In **Course Prices**, find that exact draft and choose **Set first price**.
3. Enter the agreed price and complete the same review/confirmation process.
4. Reload the saved course in Tutor, check it, and publish separately when ready.

Setting a price does not publish the course. If the price saved but publishing is refused,
keep the draft and ask the site administrator; do not set the first price again.

## Entering amounts

- Use numbers such as **60** or **60.50**, without £ signs or commas.
- Regular must be above zero. Sale must be lower than Regular.
- For no sale, leave Sale empty. Do not enter 0, a dash or the word “none”. A displayed dash means leave that confirmation box empty.
- Prices use GBP. Ask the site administrator if a different currency appears.

Confirmations expire after ten minutes. If the current price changed, or a confirmation
expired/was already used, check a fresh list before preparing another review.

A successful published-price change takes effect now; it does not schedule a sale end or
rewrite old orders. Check a fresh basket afterwards. If saving or restoration is unclear,
[stop and ask the site administrator](/money-help) rather than typing the old amount back.
