# Topic, date and search pages

WordPress makes some pages on its own. Click a topic on a blog card and you land on that
topic's page; a visitor who searches gets a results page; there are also pages by month and
by author. These used to look like a plain, unstyled website. They now match the rest of the
site.

**There is nothing to edit on them.** They are built from your articles, so the way to change
one is to change the articles.

| What decides it | Where |
|---|---|
| Which articles appear, and their titles, pictures and topics | **Posts** |
| Which topic an article is filed under | Choose an existing Category in the article editor; request a new topic from the webmaster |
| How many articles fit on one page before it splits in two | Ask the webmaster; this is not a content-account setting |

The headings, the Newer and Older buttons and the "nothing here yet" wording are part of the
design.

## Set your display name before you publish

The author page reached from an article's byline uses the public display name on your account.

Open your own profile from your name in the dashboard and find **Display name publicly as**. Choose the name you want readers to see. This changes your byline across articles; it does not provide access to other people's accounts. If the control is unavailable, ask the webmaster.

## Three gaps worth knowing about

**There is no search box anywhere on the site.** Search works if a visitor types an address
by hand, but nothing on the page invites it. Adding one is a design change rather than a
correction, so say if you would like it.

**Search finds ordinary pages too**, not only articles. Searching "log" returns the Log in
page alongside any matching articles. The webmaster is aware.

**A page-not-found message** means a visitor followed an unavailable or mistyped address. Send the broken link to the webmaster; do not delete another page to try to repair it.
