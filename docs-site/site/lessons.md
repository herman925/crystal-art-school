# Lessons

Start from **Content Hub → Manage Courses**, click the course title, and open **Lessons**. Use the pencil beside a lesson to edit it. Work only on courses assigned to your content account. Save that lesson with its own **Update** button, which appears after you change a field.

Use **Expand All** if the lessons are inside collapsed topics. Point at a lesson row to reveal
the pencil. For a new lesson, use **+ Lesson** inside the intended topic and enter its name first.

Each lesson has these content controls:

- **Name** — the lesson title shown in the syllabus
- **Content** — the description for this lesson. The syllabus also shows a plain-text
  version, so keep it focused on what this lesson teaches
- **Video** — the film for that lesson
- **Featured Image** — the lesson’s own cover, separate from the course gallery
- **Number of Lessons in This Film** — normally one; use two when one film covers two numbered lessons
- **Focus, Tools & Techniques and Learning Outcome** — the lesson details shown when its syllabus row is expanded

## Lesson Descriptions

Each lesson's own description and cover appear beneath its video.
The description appears once. Without a lesson cover, the text uses the full width;
without lesson text, the description is left out. The course introduction and course
photographs do not fill these gaps.

Reopen the saved lesson and check its words, film and file list before directing students to it. Course fields and lesson fields have separate save controls; saving one does not save unsaved changes in the other.

In the lesson editor, use **Exercise Files → Upload Attachment** for notes or reference
photographs. Choose or upload the file in Media, select it, and save the lesson with its
own **Update** button. Images appear in the student's reference-photo panel; documents
appear in Course materials. A file shared by the course and lesson appears once in the
materials list.

To replace a file, remove the old selection, add the replacement, and save. Uploading a
second version alone does not remove the first. Removing the final course/lesson reference
revokes that student's old download link. Use separate copies for public photographs and
paid materials; do not permanently delete a shared file while another course uses it.

## Upload a lesson video

**You can upload the film here in WordPress. You do not need a Bunny login or any embed code.** Start from **Content Hub → Manage Courses → course → Lessons**, open the intended lesson, and find **Lesson video**. For a new lesson, enter its name first.

1. Choose **Upload video** and select the original video file on your computer.
2. Keep this tab open while **Uploading** shows the percentage. The file goes directly to Bunny; it is not added to the ordinary WordPress Media library.
3. Wait through **Processing**. Bunny is preparing the film for playback; 100% transferred does not mean it is ready yet.
4. When **Ready** appears, preview the film and check its duration. The duration is filled automatically.
5. Use this lesson’s **Update** button, or **Save** for a new lesson. Reopen the lesson to check the saved film and duration.

Uploading and previewing prepare a selection. **The lesson’s save is what puts that film into use.** Course changes have their own separate save control.

## Choose an existing film or replace one

**Choose existing** opens the approved-film list. Select the intended title, wait for **Ready**, preview it, then save the lesson. You can reuse an approved film without uploading it again.

To replace a film, choose **Upload video** and follow the same steps. The currently saved film stays in use while the replacement uploads or processes. Once the new film is Ready, preview it and save the lesson. **Keep saved video** lets you abandon the proposed replacement.

**Remove from lesson** stages removal from this lesson; save to apply it. It does not permanently delete the film from Bunny or remove it from other lessons. Ask the site administrator to deal with permanently deleting unused films.

## If the upload stops

Leave the saved lesson film in place. Choose **Resume upload**, then select the **same original file in the same browser**. The original filename, size and modification date must match. Resume is available only while the transfer’s authorisation/resource is still valid; it is not an indefinite backup.

**Check status** asks Bunny for the current result. If you return after the film has processed, check its status, preview the Ready film and save the lesson. If it was already Ready when you closed the editor, use **Choose existing** to find it instead of uploading it again. If you save a new lesson while its transfer is unfinished, reopen that same lesson to find the pending upload.

**Cancel upload** stops this transfer and prevents it being attached by that job. The saved lesson film stays unchanged. Closing the tab does not keep uploading; you may need to resume when you return.

If you see an expired-session message, reopen the lesson. If the result is unclear or the page asks for an administrator check, send the lesson name and the exact message to the site administrator before starting another upload. Do not submit the same film repeatedly.

## About the videos

Paid lesson films use Bunny through this WordPress control. The separate [Free Videos](/free-videos) page keeps its YouTube-link workflow. **Course Highlights Video** is a separate [public preview in Course](/courses#course-highlights-video-public-preview). Use a film approved for public viewing there.

Access checks and sharing restrictions are maintained by the site administrator. Keep paid films and their video addresses private; a video address is not permission to share the film.

Keep the original film on your own computer/storage. The website's player and current direct-download
blocks are not a promise that every form of copying or screen recording is prevented.

Students cannot leave comments, questions or notes under a lesson at the moment. That is switched off on purpose.

## Free preview lessons

A lesson explicitly marked as a preview may be watched without buying the course. Check which lessons are intended to be public rather than relying on an old count. Preview video does not make paid course downloads freely available. Agree a preview change before publishing it.
