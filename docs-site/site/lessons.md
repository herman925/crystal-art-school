# Lessons

Start from **Content hub → Manage Courses**, click the course title, and open **Curriculum**. Use the pencil beside a lesson to edit it. Work only on courses assigned to your content account. Save that lesson with its own **Update** button.

Each lesson has these content controls:

- **Name** — the lesson title shown in the syllabus
- **Content** — the description for this lesson. The syllabus also shows a plain-text
  version, so keep it focused on what this lesson teaches
- **Video** — the film for that lesson
- **Featured Image** — the lesson’s own cover, separate from the course gallery
- **Number of Lessons in This Film** — normally one; use two when one film covers two numbered lessons
- **Focus, Tools & Techniques and Learning Outcome** — the lesson details shown when its syllabus row is expanded

## Lesson Descriptions

The deployed correction uses each lesson's own description and cover beneath the video.
The description appears once. Without a lesson cover, the text uses the full width;
without lesson text, the description is left out. The course introduction and course
photographs do not fill these gaps.

Reopen the saved lesson and check its words, film and file list before directing students to it. Course fields and lesson fields have separate save controls; saving one does not save unsaved changes in the other.

In the lesson editor, use **Exercise Files → Upload Attachment** for notes or reference
photographs. Choose or upload the file in Media, select it, and save the lesson with its
own **Update** button. Images appear in the student's reference-photo panel; documents
appear in Course materials. A file shared by the course and lesson appears once in the
materials list.

To replace a file, remove the old selection, add the replacement, and save. Uploading a
second version alone does not remove the first. Removing the final course/lesson reference
revokes that student's old download link. Use separate copies for public photographs and
paid materials; do not permanently delete a shared file while another course uses it.

## About the videos

Course films are hosted separately from the site's photographs and text. Each lesson's approved video setting points to the intended film. Access checks and sharing restrictions must be maintained by the site administrator; do not assume that possessing a video address is permission to share it.

For a new film or replacement, ask the site administrator to arrange the upload and update
the lesson’s approved film reference. Editing the lesson does not upload a film.

Students cannot leave comments, questions or notes under a lesson at the moment. That is switched off on purpose.

## Free preview lessons

A lesson explicitly marked as a preview may be watched without buying the course. Check which lessons are intended to be public rather than relying on an old count. Preview video does not make paid course downloads freely available. Agree a preview change before publishing it.
